# Explicit fixed Normal CJ runtime

The native source can acquire and assemble the declared **Normal body, white vest, denim and matching sneaker** profile, then register it as canonical/legacy skin0 after successful GPU upload. This is an explicit supported subset, rather than a claim about every wardrobe, body morph or the target server's initial haircut. Actual app/device scene acceptance remains separate from the host resource tests.

## Resource graph

`NativeCJProfile` accepts one bounded schema, `cj-normal-vest-denim-v1`. The private descriptor carries the actual byte lengths, SHA-256, CRC32 and assembled content identity. Public code contains the schema and recipe, with no owner checksums or asset data.

The optional prepared graph contains one descriptor and twelve original files: the player template, five component DFFs, five exact TXDs and clothes rules. The tested owner selection totals **1,809,605 original bytes**. Existing pieces are copied into a new regular private overlay; no IMG/CAB copy or model conversion is required.

`prepare_native_cj_profile.py` stages that explicit selection under `local-only/resources-v1/generated/`. The normal resource producer adds only that complete declared overlay. Existing content-addressed blobs remain reusable. The old prepared package stays valid without the optional profile.

`native_resource_server.js` reserves only the fixed profile's logical prefix and serves declared catalogue files under its existing approved real roots. Requests pass the actual server's Host, Origin and LAN join checks first. Missing/unknown profile paths return locally; they do not fetch the original website.

## Native admission and registration

- Metadata is limited to64KiB before append. Individual bodies are limited to4MiB, with a32MiB aggregate encoded budget and the existing bounded decoder limits.
- `NativeCJRuntimeLoader` reuses the verified streaming stock-file sink for size, SHA-256 and CRC32 checks. It uses the installed prepared reader first. Installed misses/errors fail closed; development may use the configured Mac origin. Dedicated network sessions disable automatic cookies/credentials/caches and reject redirects. Only an explicit snapshot of this app's own `zgta_access` token is eligible for the thirteen exact paths.
- A prepared-store admission token distinguishes same-content repairs as well as source/mode changes. Load/reset/source identities are checked during acquisition and again after actual GPU upload. Old cancellation/failure callbacks cannot revoke a newer model.
- `NativeCJRuntimeModel` owns this optional GPU family separately from ordinary and downloaded SA-MP models. Renderer publishes its actor and `pedModels["0"] = "null"` together. The original `null`/PLAYER1 gait identity is preserved; no ordinary-ped alias is used. Pending selection is applied only after registration.
- The legacy adapter retains canonical zero instead of losing it through the ordinary-ped conversion catalogue. Render readiness remains the renderer's responsibility. Other mapped, unsupported and custom IDs preserve their existing resolution.
- Optional prepared admission also checks the declared graph, assembly and actual skeletal upload. A malformed optional profile cannot turn into a substitute character.

The shared animation library, normal movement/controller, rider and world systems remain their existing implementations. This change does not claim new retail animation, controller, full wardrobe or browser-CJ parity. The archived browser explicitly excludes model `null`/skin0; it still needs its own player assembler before it can display this profile.

## Validation boundary

The public profile suite uses generated geometry/textures and exercises the actual producer/parser, identity, bounds, corruption and missing-role rejection. Private tests use only the selected owner files, actual production HTTP serving, native acquisition, persistent prepared storage and Metal upload/draw. Their exact reports, inputs, earlier failures and hashes stay private.

Observed checks:

- Authored profile/parser:24 Swift checks; producer composition/preservation checks also pass.
- Actual native acquisition/registration/persistence:34 checks, including seven real GPU uploads, cancellation/replacement, the post-upload source fence, installed no-network reads and same-content admission replacement.
- Actual server Host/Origin/join, exact GET/HEAD, method and path handling:25 checks; ephemeral listeners closed.
- Final readback uses the already verified shared CLP1 idle clip. Independent RGB coverage finds13,930 nonblack geometry pixels, and visual inspection shows the assembled standing body. Alpha coverage alone is explicitly excluded as geometry proof.

The successful replay reuses the completed executable only after matching all27 native source snapshots and test bytes plus its SHA. The installed transport fixture has an explicitly synthetic core validator and real CJ decoders; it does not certify a playable world. Complete arm64 iPhone Release and universal Simulator Debug app builds now pass with210 frozen inputs unchanged. Version113 is normally installed on the iPhone and QA Simulator; actual CJ selection/rendered app scene and CJ controller/gait acceptance remain pending. The normal phone foot/jetpack trials still use its existing skin7, not a substituted CJ acceptance claim.
