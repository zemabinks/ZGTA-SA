# Technical research records

Historical CORE reports are grouped by subsystem: `audio`, `characters`, `combat`, `gameplay`, `movement`, `network`, `rendering`, `resources`, `ui`, `validation` and `vehicles`.

These records retain the scope and limitations of each development cycle. A historical fixture result is not proof that the entire game matches retail. Original-derived owner measurements and private captures remain outside the public source repository.

For current priorities and coverage, read the [gameplay checklist](../development/CORE_GAMEPLAY_PARITY.md), [journal](../development/CORE_GAMEPLAY_JOURNAL.md), [feature matrix](../development/FEATURE_MATRIX.md) and [project status](../PROJECT-STATUS.md).
