# Core104 character identity across clients

## Reproduced boundary error

The physical browser/native comparison showed different characters for the same
wire skin ID. The native exporter had used positions in `world/peds.json`, an
animation/style list, as model IDs. The shipped browser resolves explicit IDs
from its separate pedestrian catalogue. For example, browser wire7 is `male01`
and wire14 is `bmori`; the earlier native index associated7 with `bmori`.

`tools/assets/prepare_native_models.py` now reads the explicit ID/model/dictionary records.
It validates identity, bounds, resource names and duplicate IDs rather than
inventing a translation from list positions. Explicit aliases sharing the same
model and dictionary remain representable; conflicting aliases fail closed.
Reindexing preserves every existing converted model's bytes.

The independent server and native client retain their actual wire values in
both pedestrian and driver rows. The correction happens at resource export,
where the mismatch originated. The legacy SA-MP catalogue is regenerated by
original model name against the corrected native index.

## Separate Maccer import

Browser wire2 resolves to Maccer. Its owner-local DFF/TXD pair matches the
corresponding retail IMG resources exactly. The additional converted model has
1,065 vertices,33 skeletal frames and32 bones. Mesh, atlas, parts and SKN1 data
are validated separately from the265-model metadata migration.

The adopted private overlay contains266 models. Its six files comprise the
new index, the corresponding SA-MP catalogue and four Maccer files. They are
installed into a private copy-on-write asset tree; shared archived files are
not rewritten. A fresh server origin prevents mixing old cached metadata with
the corrected pair. All six resources match their manifest byte counts and
hashes over an actual authorized HTTP request.

The browser explicitly aliases IDs149 and293 to OG Loc, while canonical SA-MP
149 is Smoke. Neither resource is supplied by this overlay. These namespaces
are not assumed universally interchangeable. Missing resources remain explicit.

The canonical SA-MP inventory still has45 unresolved IDs after this one model
addition. CJ requires its segmented clothing/body assembly; supplemental models
require their own resources. The existing WRL2 atlas exporter resamples into
128-pixel cells, while the inspected Maccer source texture is256 pixels. The
runtime DFF/TXD importer retains that original texture; complete converted-asset
texture fidelity remains a known difference. Exact original animation, gameplay
and physical performance are not inferred from these checks.

All original resources, extracted catalogues, generated files and captures stay
local-only. The public changes are independently authored converter and test
source.
