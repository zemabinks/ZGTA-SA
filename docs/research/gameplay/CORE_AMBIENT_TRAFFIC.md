# Native ambient traffic implementation scope

The native client has a separate compact-traffic store and scene. It decodes
traffic records, predicts road/free movement, loads matching original road and
vehicle resources, and retires state when connections or asset sources change.
Registered vehicles suppress their corresponding compact replica.

Nearby traffic can supply bounded server-owned contact bodies. The client can
request materialization of an original traffic vehicle, but that request alone
does not grant driving authority. A compatible server must register the vehicle
and publish the resulting control state.

Optional owner-provided traffic occupant metadata selects original character
resources and seated poses. These actors remain separate from human player
rosters. Missing metadata or unavailable resources do not produce substitute
characters.

Compact astride riders use original optional hit/fall clips and retain their
completed down pose. A driver's detached lifetime is separate from the car and
its passengers. Ready passengers retain their last completed pose when that
driver is thrown; removing or replacing their authoritative car retires them.
Compatible original-model uploads preserve this animation ownership.

A completed driver may match an already admitted server NPC of the same skin.
Local generation, age and proximity rules constrain this presentation handoff.
It preserves server-owned health/goals and never manufactures a pedestrian or
human roster entry. The landed-feet calculation is distinct from ordinary
upright vehicle exit. Broader collision-driven ejection, registered passenger
handle transfer, driver gun/look/voice behavior, traffic combat and
authoritative jacking remain incomplete. Native scene admission also remains
narrower than the original browser's quality-dependent traffic budgets.

Main lamp selection uses time, weather and actor identity. Brake inputs use the
same selected motion sample as vehicle presentation. Typed compact audio sources
retain their own identity and stable candidate ordering through the common
vehicle-audio path. This does not establish audible playback or complete
headlight beams and model-specific emergency effects.

Traffic AI, original spawn density, signals, routes, police and server decisions
are separate systems. A server must publish compatible traffic records; this
client work does not create the original service's server implementation.

The regression gates use authored records and geometry. Optional reference
inputs and all original game data remain local. Selected application cases use
controlled records through the independent backend and original owner resources.
Those cases do not establish original traffic AI, live original-server driving,
physical-iPhone performance or original-PC gameplay parity.

### Ordinary traffic shots

The compact shot receiver now returns presentation observations to the native
renderer immediately. The current rider path uses the loaded car-frame muzzle
fallback until seated gun controllers and held weapons are implemented. Shared
tracers, water crossings and material-aware blood/spark/dust presentation reuse
the available native effect resources. Audio attacks have a positioned path and
pass-by sweeps use sample time. Neither path mutates authoritative health.

The current source chain (including physics, audio and transport), universal
Simulator and arm64 iPhone builds pass. Normal retained-data joins and the
controlled traffic, bike and five typed-shot cases pass, with 46 screenshots
reviewed. The test uses authored server trajectories and rays with original
local geometry and rigs; it does not prove original traffic AI or physical
vehicle driving. A positive application tracer submission and separate real
Metal checks do not establish that each short-lived impact was visible in the
screenshots. Audible output, seated gun pose/holders, procedural fallback FX,
complete local-hit integration and original retail behavior remain unverified.
Original resources, private reference captures and test observations stay local.

### Human and local ordinary-shot follow-up

Human and compact traffic shots share the native presentation path while
retaining distinct source identities. Remote struck metadata feeds the
existing original-animation controller without applying presentation damage.
Native local ordinary shots select eligible live foot targets, current
vehicle bounds and occupants through typed owner/source guards. Collision
coverage remains required before targets beyond the known world can be used.

The current complete source chain and both native SDK products pass. Normal
four-join, full controlled traffic and normal-input local pistol/shotgun cases
pass; 62 captures across these cases are reviewed. The own-fire case observes
head and vehicle hit reports, crouched fire, actual reload inventory changes
and subsequent firing. Captures do not establish continuous contact or
animation fidelity, every transient impact or audible playback. A vehicle hit
report alone does not establish vehicle health authority. Original traffic AI,
complete browser/native damage consistency and retail fidelity remain open.
